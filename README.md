## Features

- Get all products
- Get a product by ID
- Create a new product
- Update a product
- Delete a product
- Search products by title
- Filter products by quantity
- Error handling
- Request validation

## Technologies Used

- Node.js
- Express.js
- JavaScript
- Postman

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | /api/inventory | Get all products |
| GET | /api/inventory/:id | Get product by ID |
| POST | /api/inventory | Create a product |
| PUT | /api/inventory/:id | Update a product |
| DELETE | /api/inventory/:id | Delete a product |
| GET | /api/inventory/search?search=laptop | Search products |
| GET | /api/inventory/filter?minQuantity=5&maxQuantity=15 | Filter products |
